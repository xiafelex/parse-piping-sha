# 成达印尼项目SHA解析器

本目录从蓝星项目已验证解析器复制而来，后续的成达兼容性修改只在本目录进行，不修改蓝星解析器。

当前成达专用差异包括：

- 从`Sheet221`识别594×420 mm的A2横向页面；
- 将`PSMcluster0`的32768单位坐标换算为16800页面单位；
- 使用结构证据识别低编号模板文字，而不依赖蓝星对象编号范围；
- 在SVG中记录实际毫米图幅，并按该尺寸生成PDF；
- 修正无PSM文字框时遗留上一条文字边界的问题。
- 解析`Sheet221`的`0x13`自由轮廓及`StyleCluster`填充色，直接恢复成达
  红蓝标识和中英文矢量字标，不依赖外置图片。
- 图签单行文字按PSM单元格真实中心使用字体中央基线；`Scale`、`Sheet`
  等多行字段按整个字块居中，法律声明等左对齐段落仍保留SHA原始锚点。
- 对 Chromium PDF 在正式落盘前严格校验文件头、结束标记、加密状态、页数
  和页面方向；发布过程不再二次重写页面对象，避免位图/字体资源引用丢失。
- 正式文件原子替换完成后恢复父目录的 Windows ACL 继承，避免临时文件的
  沙箱专用权限导致普通用户或 PDF 阅读器无法打开。

转换入口：

```powershell
python "D:\研发工作\Cursor\PCF解析\成达印尼项目\SHA转换程序\convert_chengda_sha_to_pdf.py" --force
```

`node_modules`是指向现有Playwright运行依赖的目录联接，只共享第三方运行库，不调用或修改蓝星解析代码。
